# PMG Paper-Faithfulness Audit — 2026-06-22

## Scope and classification

Baseline: *Parametric Motion Graphs* (`PMGFullPaper.pdf`), especially §§3–4. The paper delegates node construction to Kovar–Gleicher 2004; therefore code inspired by that earlier system is not automatically faithful to the PMG paper's edge algorithm.

- **FAITHFUL**: directly implements a structure or algorithm stated in the paper.
- **APPROXIMATION**: serves the paper role with materially different or partial machinery.
- **EXTENSION**: useful engineering/product behavior not required by the paper algorithm.
- **MISSING**: paper-required role has no current implementation.

## Smallest next code branch

Implement one offline **candidate-window/cycle extractor** for a longer BVH clip, returning extracted frame range plus source provenance. This closes part of the largest upstream gap—paper/KG04-style example extraction—without changing runtime, graph format, interpolation, or controller policy. Automatic motion-family discovery remains out of scope until corpus evidence requires it.

## Claim boundary

Current implementation is strongest on paper §§3.1–4: Kovar transition distance, sampled AABB edge construction, and k-nearest runtime lookup. Motion-space authoring is an approximation of the delegated KG04 pipeline. Diagnostics, quality/contact gates, persistence, CLI, and viewer are engineering extensions. No evidence here establishes paper-result, corpus, visual-quality, or performance reproduction.
